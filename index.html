Como jogar

O primeiro clique é sempre seguro. Depois disso, confie nos números.

Revele os telhados

Clique numa telha para abri-la. Áreas vazias se abrem em cascata até encontrar números.

Leia os números

Cada número diz quantas minas tocam aquela telha, inclusive nas diagonais.

Marque com a patinha

Botão direito ou segurar no celular marca uma mina. Clique num número já cercado de patinhas para abrir tudo em volta.

Visão Felina

Travou? Use a Visão Felina para abrir uma telha segura. São 3 por ronda e cada uma custa pontos.
